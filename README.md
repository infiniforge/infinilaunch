# InfiniLaunch
InfiniLaunch is a planned Android launcher and application organizer. This repository is currently a
placeholder; see the [application scope and implementation status](docs/APPLICATION.md).

**Status: planned placeholder.** This checkout currently contains project guidance
only. It has no Android application source, Gradle build, app-level `build.sh`, or
APK, so it cannot be built or installed yet.

The planned app is an Android application launcher. Its scope, supported Android
versions, and package/activity interactions remain to be designed. It should use
public Android launcher and package APIs and keep its build independent from the
other Infiniforge applications. No storage-backend integration is currently
specified or implemented.
